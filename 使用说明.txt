你之前看到的 Node.js 报错不会再出现。

这个版本改为纯 Python + 腾讯官方 qqbot-agent-sdk 思路：
1. Windows 电脑安装 Python 3.11+（仅在你自己本机打包时需要）。
2. 双击 build_windows.bat。
3. 完成后得到 dist\QQ关键词自动回复.exe。
4. 以后只需运行这个 EXE。
5. 填 AppID、AppSecret。
6. 默认关键词：有意 / 有意愿 / 有意者 / 有意向。
7. 命中群消息后回复 1。

如果你不想在电脑安装 Python：
把整个工程上传到 GitHub，GitHub Actions 会在 Windows 云主机上自动构建 EXE，下载 Actions 生成的 artifact 即可。

本程序基于腾讯当前公开的 qqbot-agent-sdk 接口设计，实际可监听的群消息范围仍取决于 QQ 开放平台给机器人开通的权限。
