QQ关键词自动回复 v3

功能：
- 监听 QQ 群消息
- 消息包含“有意 / 有意愿 / 有意者 / 有意向”时自动回复“1”
- 可自定义关键词、回复内容、冷却时间和指定群 ID

使用：
1. 在 QQ 开放平台取得 AppID 和 AppSecret。
2. 运行 EXE。
3. 填写 AppID、AppSecret。
4. 确认关键词、回复内容、冷却时间、群 ID。
5. 点击“保存配置”。
6. 点击“启动机器人”。
7. 查看运行日志。

本版本修复：
- WSCallbacks 缺少当前 SDK 必需参数
- HTTP client not initialized - not connected
- 使用官方 SDK 当前示例的 httpx.AsyncClient + QQApiClient.setup() 初始化方式

配置位置：
%APPDATA%\QQKeywordAutoReply\config.json

安全：
AppSecret 不要发给他人或上传到 GitHub。
